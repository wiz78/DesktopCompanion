🤖 FriendlyBot

Web Firmware Installer

Install or update FriendlyBot firmware directly from your browser over USB. No command line, drivers, or software installation needed.

Quick Instructions:
  1. Connect your ESP32-S3 board to this computer using a USB data cable.
  2. Click Install Firmware below and select your device's serial port.
  3. Follow the on-screen prompt to flash. Installation takes about 30 seconds.
Your browser does not support Web Serial. Please open this page in Google Chrome or Microsoft Edge on a desktop computer.

Troubleshooting: If your board is not detected, hold the BOOT button, press and release the RESET button, then release BOOT to enter ROM download mode.
